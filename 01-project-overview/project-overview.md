# Project Overview

## Smart Weather Platform

The Smart Weather Platform is an Agile/Scrum project simulation managed using Jira.

The project focuses on planning and managing a weather platform that provides users with weather information, location-based services, forecasts, alerts, and supporting business capabilities.

## Project Management Approach

The project was managed using the Agile/Scrum framework in Jira.

Key activities included:

- Requirement analysis
- Epic creation
- User story creation
- Product backlog management
- Story point estimation
- Backlog prioritization
- Sprint planning
- Sprint execution
- Sprint tracking
- Release planning
- Roadmap planning
- Agile reporting

## Project Structure

The project was organized into five major epics:

1. Client Registration
2. Business Logic
3. Building Products and Services
4. Business Model
5. Business Innovation

- Jira Software
