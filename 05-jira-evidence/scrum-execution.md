# Smart Weather Platform – Scrum Board

## Scrum Board Overview

The Smart Weather Platform project was managed using an Agile/Scrum approach. A Jira Scrum board was used to visualize work, monitor progress, and track user stories and tasks during sprint execution.

## Board Workflow

The Scrum board followed a simple workflow:

**To Do → In Progress → Done**

### To Do
Work items that were planned for the sprint but had not yet started.

### In Progress
Work items currently being worked on during the sprint.

### Done
Work items that had been completed and met the defined acceptance criteria.

## Sprint Execution

The Scrum board was used during each sprint to:

- Track sprint work
- Monitor progress of user stories
- Identify work currently in progress
- Track completed items
- Maintain visibility of sprint status
- Support daily progress monitoring
