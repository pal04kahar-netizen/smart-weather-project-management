# smart-weather-project-management
Managed an Agile/Scrum simulation for a Smart Weather platform using Jira, translating requirements into 5 epics and 15+ user stories. Created and prioritized the backlog, planned 3 sprints, managed releases, and tracked progress using Scrum boards, Roadmaps, and Burndown/Burnup reports.
## Agile Project Documentation

This repository demonstrates an Agile/Scrum project simulation for a Smart Weather Platform.

The project documentation covers:

- Project overview and product vision
- Business and functional requirements
- Epics and user stories
- Product backlog and prioritization
- Sprint planning and execution
- Agile roadmap
- Scrum board structure
- Sprint reporting and progress tracking

### Documentation Note

The Agile artifacts in this repository are reconstructed project documentation based on a Smart Weather Platform project simulation. They demonstrate the planning and execution approach used for an Agile/Scrum project.

Original Jira access and historical screenshots from the earlier project period are no longer available. Therefore, the repository focuses on demonstrating the project management artifacts, decisions, processes, and Agile practices rather than presenting historical Jira screenshots as current evidence.
